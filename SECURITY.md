# Security Policy

## Supported versions

Security fixes are handled on the latest released version.

## Reporting a vulnerability

Please do not open a public issue for security reports.

Report vulnerabilities by emailing the maintainer listed in the GitHub repository profile, or by using GitHub private vulnerability reporting if it is enabled for this repository.

Include:

- affected version or commit
- operating system and architecture
- steps to reproduce
- impact and any known workaround

You should receive an initial response within 7 days.
